Resumo

[P00004 | 130:537 | NORMAL_TEXT]
Este trabalho apresenta uma interface para controle de robôs móveis por comandos em linguagem natural em português. A proposta integra um modelo de tradução para a linguagem de comandos LBML, um simulador robótico 3D e um servidor MCP com recursos de câmera e sensores de proximidade. O objetivo é tornar a interação com robôs mais acessível e investigar o uso de modelos de linguagem no controle robótico.
